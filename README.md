# Tomato - Food Delivery App

A front-end food ordering app built with React. Users can browse a menu, filter by category, add dishes to a cart, review totals, and fill in delivery details.

## Features
- Filters dishes by category (click the active category again to reset)
- Add and remove items with a quantity counter on each dish
- Cart page with per-item totals, subtotal, delivery fee and order total
- Cart indicator in the navbar that updates live
- Multi-page navigation with React Router (Home, Cart, Place Order)
- Sign in / sign up popup (UI only)
- Smooth scrolling to page sections from the navbar

## Built with
React, Vite, React Router, Context API, CSS

## React concepts practiced
- Components and props
- `useState` for UI state
- Context API (`useContext`) for global cart state
- Lifting state up
- Conditional rendering and list rendering with keys
- Client-side routing with `Link` and `useNavigate`
